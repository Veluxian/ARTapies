# 🐢✨ AR-Tapies

**AR-Tapies** es un proyecto académico de la asignatura Capstone (PTY4614) de Duoc UC.  
Busca transformar la experiencia del juego de mesa *Tartapies* mediante **realidad aumentada (AR)**, mostrando en tiempo real las interacciones de los personajes sobre el tablero físico.

## 🎯 Objetivo
- Mejorar la comprensión y disfrute del juego.
- Facilitar la incorporación de nuevos jugadores.
- Integrar **juego físico + AR** en una propuesta innovadora.
- Desarrollar competencias profesionales en **software, bases de datos, modelado 3D y gestión ágil**.

## 🛠️ Tecnologías
- **Unity** (motor principal de AR y 3D
- **Metodología SCRUM** (planificación y control del proyecto)
- **Modelado 3D y animaciones**
